MON BUDGET — V1

Fichiers prêts pour une web-app installable sur iPhone.

Fonctions :
- accueil Mon budget
- 3 catégories visibles + gestion complète
- ajout / renommage / suppression des catégories
- ajout de dépenses
- historique Transactions + filtre par catégorie
- budget mensuel modifiable
- données conservées localement sur l'appareil
- onglet Compte commun préparé pour une future synchronisation

Pour l'utiliser réellement sur iPhone, hébergez le contenu de ce dossier sur un hébergeur HTTPS puis ouvrez l'adresse dans Safari et choisissez « Ajouter à l'écran d'accueil ».

Attention : cette V1 stocke les données uniquement sur l'appareil. Elle n'est pas encore synchronisée entre deux téléphones.
